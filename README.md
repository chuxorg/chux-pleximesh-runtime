# chux-agent-mesh

chux-agent-mesh is the control-plane-ready workspace for the Chux agent mesh initiative. This repository is intentionally minimal and exists solely to host governed tasks, documentation, and automation hooks for the broader agent ecosystem.

Guardian governs the entire SDLC for this project, and all contributors must follow the rules defined in the canonical InitKit at https://github.com/chuxorg/chux-agent-initkit (version v1.0.0).

No application code lives here until Guardian explicitly authorizes it.
